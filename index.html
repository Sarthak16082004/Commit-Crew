How to Resolve a Merge Conflict

When two branches change the same line, Git marks both versions:

<<<<<<< HEAD  (your branch)
<h1>Welcome to Commit-Crew</h1>
=======
<h1>Commit-Crew Portfolio 2024</h1>
>>>>>>> feat/other-branch
  1. Open the file in VS Code — it highlights conflicts in red/green
  2. Click "Accept Current Change" or "Accept Incoming" or edit manually
  3. Remove all <<<, ===, >>> markers — none should remain
  4. Run: git add . then git commit -m "fix: resolve merge conflict"
